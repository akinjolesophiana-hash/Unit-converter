# Unit Converter
A menu-based Python application that converts different units of measurement

## Features 
-Length conversion
-Weight conversion
-Volume conversion
-Menu-based navigation
-Separate python modules for different conversions

## Technologies Used
- Python 3
  
## Project Structure
- main-converter.py - Main program
- length.py - Length Conversion
- weight.py - Weight Conversion
- volume.py - Volume Conversion
  
## How to Run
1. Make sure Python 3 is installed.
2. Download or clone this repository.
3. Run the main-converter.py file.
